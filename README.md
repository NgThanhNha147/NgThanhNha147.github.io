# Thanh Nha Developer Portfolio

Interactive Full-stack Developer portfolio built with React, TypeScript, Three.js, GSAP and Lenis.

Live site: `https://NgThanhNha147.github.io`

## Local development

```bash
npm install
npm run dev
```

Replace `public/images/avatar-placeholder.svg` with a portrait and add the final CV at `public/cv/Thanh-Nha-CV.pdf` without changing the components.
